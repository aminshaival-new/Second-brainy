# Vibe Coding

> AI-assisted / AI-first software development — tools, techniques, and how to deliver it as a service to clients in 2026.

---

## What It Is

Vibe coding = describing what you want in plain language and letting AI write the code. Coined by Andrej Karpathy; Collins Word of the Year 2025.

- 92% of US developers use AI coding tools as of 2026
- 41% of all global code is now AI-generated
- 40% faster coding, 35% less debugging time (industry average)
- 78% of global dev teams have adopted AI code assistants

## The Main Tools

### GitHub Copilot
- Largest by users: 20M cumulative, 1.8M paying (~55% market share)
- Integrates into VS Code, JetBrains, and other IDEs
- Solves 56% of SWE-bench tasks
- Best for: teams already in VS Code, broad language support

### Cursor
- AI-native IDE built from scratch around AI assistance
- 18% market share in 18 months — $9B valuation, $900M Series C
- Solves 52% of SWE-bench tasks
- Best for: developers who want deep AI integration in every part of their workflow

### Claude Code (Anthropic)
- CLI-based agentic coding tool — not an IDE
- Claude Sonnet 4: 72.7% SWE-bench (top performer)
- Claude Opus 4: 72.5% SWE-bench
- Best for: complex codebases, senior engineers, multi-step agentic tasks
- Works alongside any IDE

## 2026 Trend: Vibe Coding → Agentic Engineering

The terminology is shifting from "vibe coding" (personal productivity) to "agentic engineering" (production-grade):
- AI doesn't just autocomplete — it plans, executes, tests, and iterates
- Full features can be built with natural language specifications
- Code reviews, debugging, refactoring — all AI-assisted
- Non-developers can build functional prototypes (with oversight)

## Delivering Vibe Coding as a Service

Value proposition for clients:
- "Build your MVP in weeks, not months"
- "Iterate 10x faster once it's live"
- "Your non-technical team can describe features; we build them with AI"

Key workflow for client delivery:
1. Requirements gathering (natural language spec)
2. AI-assisted scaffolding (Cursor + Claude Code)
3. Human review for architecture and security
4. Iterative AI-powered feature development
5. Automated testing + deployment

Pricing models:
- Sprint-based (2-week chunks, fixed price)
- Hourly with AI leverage pass-through (client sees speed benefit)
- Outcome-based (delivered feature set, not time)

## Risks and Quality Control
- AI code requires human review for security vulnerabilities
- Test coverage is critical — AI can introduce subtle bugs
- Architecture decisions still require senior human judgment
- Always audit AI-generated code before production deployment
